# Hupfumi

Hupfumi is a Zimbabwe-focused digital marketplace for jobs, services, products, escrow payments, KYC, messaging, and admin workflows.

The platform brings buyers, sellers, freelancers, and businesses into one trusted environment where discovery, communication, payment handling, and moderation work together. It is designed to reduce friction in everyday commerce while increasing confidence in every transaction.

Hupfumi is built around local business realities: mobile-first usage, secure account management, verification flows, and support for modern marketplace operations at scale.

## Platform Overview

Hupfumi is intended to be a practical economic layer for local trade and services. Users can find work, offer services, list products, manage orders, and communicate safely, while administrators keep the ecosystem organized and trustworthy.

## What It Includes

- Marketplace browsing and search for jobs, services, and products
- Authentication with optional Google sign-in and persistent sessions
- Light/dark mode with stable startup behavior
- Wallet, payments, and order flows built for secure transactions
- Real-time messages and notifications for faster coordination
- Admin tools for moderation, disputes, KYC, and analytics

## Stack

- Frontend: React 19, TypeScript, Vite, Tailwind CSS, TanStack Router, TanStack Query, Zustand
- Backend: Node.js, Express, MongoDB, Mongoose, Socket.IO, BullMQ, ImageKit, Paynow, Arcjet
